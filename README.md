# vps-pair-kit

Приложения на HOME → локальный sing-box → зашифрованный SS2022 TCP → EGRESS.

Перед установкой агент читает [руководство](VPS_PAIR_AGENT_GUIDE.md). Docker и UDP вне v1. Комплект готовит локальные конфиги, но сам не устанавливает сервисы на VPS.

**Владельцу:** если агент открыл локальный `.env`, заполните только недостающие IP, имена администраторов и пути к уже существующим файлам SSH-ключей. Команды в терминале выполнять не нужно. Не вставляйте содержимое приватных ключей или пароли в `.env` и чат. Ключ SS2022 помощник генерирует локально.

**Агенту:** создай/открой `.env` через `python3 scripts/kit.py init --open`, затем сам запусти `python3 scripts/kit.py check`, `python3 scripts/kit.py render` и `python3 -m unittest discover -s tests -v`. Если `check` назвал незаполненные поля, объясни их обычными словами и дай владельцу заполнить файл в локальном редакторе; затем повтори проверки. Не угадывай роли VPS по чужим SSH aliases. Не проси владельца запускать эти команды.

Файл `.env` исключён из git и имеет права 0600. Сгенерированные файлы в `.rendered/` содержат секрет и тоже имеют права 0600. Помощник не подключается по SSH. Серверные действия согласуются отдельно; порядок проверки, установки и отката — в руководстве.

В [шаблонах](vps-pair/templates/) есть обе proxy-конфигурации, systemd units, env приложений, SSH aliases и эксплуатационные документы. Старые профили Dante/SOCKS/urltest удалены.
