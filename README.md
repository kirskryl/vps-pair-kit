# vps-pair-kit

Два сценария: настроить изолированную пару новых VPS HOME/EGRESS либо установить только Hermes Agent на уже подготовленный сервер. В сценарии новой пары Hermes устанавливается на HOME только по согласованию с владельцем.

Начните с [скилла](SKILL.md). Для новых VPS он ведёт по [полному pipeline](references/pipeline.md): цели, доступ, шлюз, приёмка и, если нужен, Hermes. Для готового сервера есть [вход «только Hermes»](references/hermes-only.md), который пропускает создание пары. Настройка Hermes включает ChatGPT, Telegram, изображения и русский голосовой ввод. [Руководство SS2022](VPS_PAIR_AGENT_GUIDE.md) относится к отдельному транспортному профилю. Docker и UDP пока вне комплекта. `scripts/kit.py` готовит локальные конфиги SS2022 и сам не подключается к VPS.

**Владельцу:** если агент открыл локальный `.env`, заполните только недостающие IP, имена пользователей и пути к SSH-ключам. Если на новых VPS пока есть только root-доступ, укажите `root` как временного пользователя: агент создаст отдельных администраторов и обновит файл. Команды в терминале выполнять не нужно. Не вставляйте содержимое приватных ключей, токены или пароли в чат. Ключ SS2022 помощник генерирует локально.

**Агенту:** сначала выбери сценарий из запроса. Для новой пары выполни `python3 scripts/kit.py status` и покажи абсолютный путь к `.env`; только если файла нет, выполни `init --open`. До выбора транспорта уточни, нужен ли Hermes; имеющийся явный запрос на него уже считается ответом. При временном root-доступе используй `check-bootstrap`; после создания администраторов — `check`, а `render` только для SS2022. Для готового сервера пропусти `.env` и этапы пары. Локальные тесты: `python3 -m unittest discover -s tests -v`. Не проси повторно вводить сохранённые данные.

Файл `.env` исключён из git и имеет права 0600. Сгенерированные файлы в `.rendered/` содержат секрет и тоже имеют права 0600. Локальный helper не подключается по SSH. Удалённые действия агент выполняет только на явно выбранных пользователем серверах, в пределах выбранного сценария.

В [шаблонах](vps-pair/templates/) есть обе proxy-конфигурации, systemd units, env приложений, SSH aliases и эксплуатационные документы. Старые профили Dante/SOCKS/urltest удалены.

## Автопубликация скилла

Локальный планировщик может запускать `python3 scripts/auto_publish_skill.py --commit-only` из этого checkout, а затем отправлять готовый коммит через подключение GitHub. Скрипт подготавливает только `SKILL.md`, `references/*.md`, `README.md` и `VPS_PAIR_AGENT_GUIDE.md`; после правки он ждёт 10 минут, проверяет ссылки, типы файлов, типичные секреты и тесты. При изменениях кода или расхождении с GitHub автопубликация останавливается: такие изменения требуют обычного коммита после проверки. Команда без флага проверяет состояние без коммита. `--publish` дополнительно отправляет коммит обычным Git, если локальная авторизация GitHub настроена.
