# Проверки перед завершением

Проверяй фактическую работу установленной версии. В закрытой заметке сохраняй результат, время и несекретное доказательство; скрывай токен бота, код входа, SS-ключи, приватные пути при публикации, содержание сообщений и сырые журналы. Владелец не должен разбирать ошибки `systemctl`, SSH или Python.

## Новая связка серверов — только для этого режима

| Проверка | Признак успеха | Если не прошла |
| --- | --- | --- |
| Изоляция целей | ID в панели и закреплённые host keys соответствуют двум согласованным ролям; команды не обращались к старому VPS | Остановить изменения и уточнить подлинность узлов |
| Доступ администраторов | На каждом новом VPS работает вход по отдельному ключу и ограниченный `sudo` | Сохранить root-доступ для восстановления; исправить пользователя или ключ |
| Маршрут | Запрос с HOME через выбранный транспорт выходит с IP EGRESS; нужные DNS и HTTPS-адреса доступны | Исправить транспорт; не включать прямой обход с HOME |
| Отказ и восстановление | При остановке только выбранного транспорта запрос приложения завершается ошибкой за ограниченное время; после запуска снова работает | Не выпускать в работу; найти обход или устаревшее соединение |
| Автозапуск | Нужные службы работают после отдельных перезапусков и поочерёдной перезагрузки двух VPS | Исправить unit и зависимости |

## Hermes — для новой пары с Hermes и для режима «только Hermes»

Перед проверками Hermes на готовом сервере подтвердите, что это именно выбранный владельцем узел, а Telegram и OpenAI/Codex доступны через его действующий сетевой выход. Если указан обязательный EGRESS, подтвердите его публичный IP. Для режима «только Hermes» проверки создания пары, новых администраторов и остановки общего шлюза не требуются; автозапуск проверяется на выбранном сервере без перезагрузки чужих VPS.

| Проверка | Признак успеха | Если не прошла |
| --- | --- | --- |
| ChatGPT | Реальный запрос Hermes проходит на модели по умолчанию; другие запрошенные модели проверены, если доступны | Завершить OAuth или выбрать доступную модель |
| Telegram | Единственный polling gateway получает текст владельца, владелец получает ответ | Исправить токен, список доступа, конфликт webhook/polling |
| Картинка | `image_generate` создаёт допустимое изображение, а Telegram доставляет его как изображение | Исправить провайдера и маршрут; объяснить ограничения Codex |
| Голос | Журнал фиксирует успешное распознавание `local whisper` на `ru`, владелец подтверждает ответ по смыслу | Установить зависимость в активное окружение, перезапустить gateway извне, повторить проверку |

При локальной разработке вместо удалённых проверок запускай тесты валидации конфигурации, прав файлов, перехода от root к администраторам, метаданных скилла и ссылок. Явно сообщай, что удалённые проверки **не выполнялись**. Если чистых VPS нет, воспроизводи первичную установку и ошибки в двух временных локальных VM. Проверка существующей пары без изменений может подтвердить распознавание текущего состояния, но не доказывает новую установку в Sweb.
