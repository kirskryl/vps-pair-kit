# Hermes на HOME: ChatGPT, Telegram, картинки и голос

Выполняй этот этап после явного запроса на Hermes: либо после подготовки новой пары, либо сразу через [вход для готового сервера](hermes-only.md). Перед командами сверь справку установленной версии Hermes и [официальное руководство](https://hermes-agent.nousresearch.com/docs/getting-started/quickstart); не выполняй непроверенный `curl | bash`. Зафиксируй используемый релиз. При новой установке Hermes работает под отдельным пользователем `hermesagent` со своим домашним каталогом, хранилищем авторизации, службой и окружением зависимостей. Существующую исправную установку сначала изучи и дополни без дублирования gateway. Трафик Telegram и OpenAI/Codex направляй по выбранному владельцем или уже действующему сетевому выходу; проверяй маршрут в реальном Hermes, а не одним `curl`.

## Подписка ChatGPT и модели

Запусти вход Hermes через OAuth-провайдер `openai-codex`. Выполняй один процесс входа. Из его вывода извлеки ссылку и одноразовый код, убери ANSI-последовательности и сразу покажи владельцу обычную кликабельную ссылку [auth.openai.com/codex/device](https://auth.openai.com/codex/device). Код покажи через закрытый локальный интерфейс; не копируй его в чат или логи. Дождись подтверждения входа или окончания срока действия кода; открытая вкладка сама по себе ещё не доказывает успех. Если вход по коду отключён, используй поддерживаемый Hermes браузерный вход PKCE с локальным SSH-пробросом порта на HOME. Не запускай параллельно второй вход. [Документация OAuth через SSH и Codex](https://hermes-agent.nousresearch.com/docs/integrations/providers).

После входа посмотри список моделей, доступных **именно этой** учётной записи. Выбери `gpt-6-luna` по умолчанию, только если она доступна, и проверь коротким реальным запросом. Если доступны `gpt-6.1-terra` и `gpt-6-sol`, проверь переключение на них и верни модель по умолчанию. Не обещай доступ к модели по одному её названию. При ошибке авторизации сохрани возможность продолжить установку и назови владельцу конкретное действие; не запрашивай в чате пароль, cookies или OAuth-токены.

## Telegram

Если версия Hermes поддерживает встроенное подключение Telegram, предпочти его: QR-сценарий может создать бота и определить числовой ID владельца. Если владелец создаёт бота через [@BotFather](https://t.me/BotFather), попроси только это действие и дай защищённое локальное поле или файл для `TELEGRAM_BOT_TOKEN`. По возможности получи `TELEGRAM_ALLOWED_USERS` через самого бота; сторонний бот для определения ID — запасной путь, а не обязательное задание владельцу. Проверь токен через Bot API без вывода в аргументах команд и логах. Убедись, что работает один polling gateway и нет конфликтующего webhook; ограничь доступ ID владельца. Попроси владельца отправить одно текстовое сообщение; проверь его получение, ответ модели, отправку ответа и подтверждение владельца. [Руководство Hermes по Telegram](https://hermes-agent.nousresearch.com/docs/user-guide/messaging/telegram).

## Картинки

При использовании подписки ChatGPT настрой `image_gen.provider=openai-codex`. Метка модели вроде `gpt-image-2-medium` для инструмента Codex носит рекомендательный характер: Hermes не может принудительно вызвать размещённый инструмент или гарантировать конкретный движок генерации. Если владелец требует **гарантированно GPT Image 2**, предложи отдельно оплачиваемый OpenAI API или другого поддерживаемого поставщика, введи ключ через защищённый интерфейс и проверь именно этот маршрут. Не создавай платных расходов без согласования. Для любого выбранного пути вызови `image_generate`, проверь файл изображения и запроси картинку через бота; в Telegram должно прийти изображение, а не только текст. [Ограничения провайдеров изображений](https://hermes-agent.nousresearch.com/docs/user-guide/features/image-generation/).

## Русский голосовой ввод

Задай `stt.enabled=true`, `stt.provider=local`, `stt.local.model=base` и `stt.local.language=ru` либо эквивалентные настройки зафиксированного релиза. Установи дополнительную зависимость `stt-whisper` из **того же checkout Hermes, который запускает gateway**. В этой установке зависимость оказалась в другом каталоге установок: на диске она была, но работающий процесс сообщал «No STT provider available». Проверь через загрузчик самого Hermes, что `faster_whisper` импортируется, выбран провайдер `local` и язык `ru`. Проверка отдельным системным Python не даёт достаточного ответа.

После изменения зависимостей или настроек перезапусти gateway из внешней административной сессии. Проверь новый процесс и повторное подключение к Telegram. Попроси владельца отправить короткое русское голосовое. Приёмка пройдена, когда журнал фиксирует успешное распознавание локальным Whisper, а ответ бота соответствует сказанному. Первая проверка может скачать модель: отведи ограниченное время и сообщи о сбое загрузки как о конкретной повторяемой ошибке, а не как о молчаливом зависании.
